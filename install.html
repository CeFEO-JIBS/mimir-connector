Install

Four steps, about two minutes. You need a Claude account and an approved email address.

https://mcp.familybusiness.se/fbp

  1. Open connector settings

    In Claude, go to Settings → Connectors, then Add → Add custom connector.

  2. Paste the URL

    Use the address above. Leave the OAuth fields empty — Mímir registers your client automatically.

  3. Sign in

    Enter the email address your access was granted to. A six-digit code arrives by email; it expires after five minutes.

  4. Ask something

    Try “What does the research say about founders who won't step back?” Claude will search the library and answer with sources.

If something goes wrong

“Couldn't register”

Usually a transient network error. Remove the connector, reload Claude, and add it again.

No access on that address

The email you entered has no active grant. Use the address your invitation was sent to.

The code never arrives

Check spam — it comes from a noreply@ address. Codes expire in five minutes; start again to get a fresh one.
